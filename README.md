## Project Summary
This project analyzes banking transaction and customer data to understand customer behavior, revenue generation, and transaction patterns across branches, products, and income groups.
The dashboard provides an interactive overview of customer financial activity, allowing decision-makers to monitor:
- Customer satisfaction (NPS)
- Revenue sources
- Transaction channels
- Customer segmentation
- Branch performance
The goal is to provide insights that help the bank increase revenue, improve customer satisfaction, and optimize product offerings.

## Project Objectives
- Which products generate the most value
- How customers interact with banking channels
- Which customer groups generate the most revenue
- Whether customer satisfaction is improving
Without clear insights, it becomes difficult to prioritize high-value customers and optimize services.

## Data Cleaning
- Removed duplicate records
- Standardized income categories
- Converted date fields to proper date format
- Created month column for trend analysis
- Verified revenue calculations
- Handled missing values

## Data Modeling
A structured model was created in Power BI to improve analysis performance.
Key relationships included:
- Customer → Transactions
- Branch → Revenue
- Product → Transaction Value
- Channel → Transaction Type
The model supports multi-filter analysis across:
- Branch
- Month
- Income band

## Insights
 — Transaction Channels
Digital channels such as mobile and online banking generate the majority of transaction value, indicating strong adoption of digital banking.

— Income Segmentation
High-income customers contribute slightly higher transaction values but middle-income customers provide strong overall revenue contribution due to volume.

— Product Value
Mortgage, loans, and checking accounts contribute the highest transaction values, showing that core banking products drive financial activity

— Customer Satisfaction
Promoters generate higher transaction values compared to detractors, indicating customer satisfaction correlates with financial engagement.

## Strategic Recommendations
Based on the analysis, the bank could:
- Invest more in mobile and digital banking channels
- Target middle-income customers with loyalty programs
- Expand high-value financial products such as mortgages and loans
- Improve service quality to convert detractors into promoters
